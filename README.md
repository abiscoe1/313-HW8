<ins>Purpose of Software:</ins>  
&ensp; Simulate a matrix library with matrix functions such as addition, subtraction, multiplication (both matrix and scalar), and transpose in both  
&ensp; the C++ and C languages.  
<ins>Files:</ins>  
&ensp; matrix_library.cpp : The C++ version of the programmed matrix library.  
&ensp; matrix_library.c : The C version of the programmed matrix library.  
<ins>Build Instructions:</ins>  
&ensp; Matrices must be hard coded into main with their entries.  
&ensp; For matrix_library.cpp:  
&emsp; Compile: g++ -Wall matrix_library.cpp -o matrix_library  
&emsp; Run: ./matrix_library  
&ensp; For matrix_library.c:  
&emsp; Compile: gcc matrix_library.c -o matrix_l  
&emsp; Run: ./matrix_l  
<ins>Testing Methodology:</ins>  
&ensp; I calculated the output of the provided equation. I then compared the outputs of my program after each operation to the calculated solutions  
&ensp; to make sure each function performs the calculations correctly. To view   the outputs, I coded a print function to display the arrays in matrix  
&ensp; form.  
<ins>Additional Information:</ins>  
&ensp; Matrices must be coded into main, the program does not ask the user for matrices.
